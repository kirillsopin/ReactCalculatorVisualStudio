# React Calculator

Готовий навчальний проєкт калькулятора на React.

## Як запустити у Visual Studio

1. Розпакуйте ZIP-архів у зручну папку.
2. Відкрийте **Visual Studio 2022**.
3. Виберіть **File → Open → Folder...** та вкажіть папку `ReactCalculatorVisualStudio`.
4. Відкрийте термінал у Visual Studio: **View → Terminal**.
5. Переконайтеся, що встановлений Node.js (LTS), потім виконайте:

   ```bash
   npm install
   npm run dev
   ```

6. Відкрийте адресу, яку покаже Vite у терміналі (зазвичай `http://localhost:5173`).

> Це React/Vite-проєкт. Для нього не потрібен .NET або файл `.sln`: у Visual Studio його зручно відкривати як папку.

## Реалізовано

- Функціональний компонент `App`.
- Хук `useState` для збереження стану калькулятора.
- Цифри від 0 до 9 та дробові числа.
- Додавання, віднімання, множення та ділення.
- Обчислення кнопкою `=`.
- Очищення `C`, видалення останнього символу, зміна знака та відсотки.
- Захист від ділення на нуль.
- Інтерактивна робота без перезавантаження сторінки.

## Перевірка

Для перевірки ділення на нуль введіть `8 ÷ 0 =` — на екрані з'явиться «Помилка».
